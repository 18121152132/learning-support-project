# 学习支持与辅导协作项目 · 原始资料

> 北辰在线学院「学习掉队以后才收到提醒」合成训练案例 · 业务调研与技术方案

本仓库收录该案例的**原始资料**与**技术方案**，用于业务挖掘、现场调研与技术落地的设计与评审。

## 如何阅读

1. 先读 `学习支持与辅导协作-业务挖掘报告.md`，了解案例的业务起点与边界；
2. 再读 `学习支持与辅导协作-现场调研报告.md`，看六类角色的陈述与相互矛盾之处；
3. 最后读 `技术方案/技术方案.md`，看技术选型、分层与验收口径。

## 说明

- 本案例为**合成训练资料**，结论均为**待验证假设**，不代表真实机构授权、生产上线或实际收益。
- 涉及学生个人信息的样例一律脱敏；报告中的编号（如 `education-f00`）指向访谈事实，请勿改写。
