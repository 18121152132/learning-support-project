# 提示词说明与运行时模板

版本：`pilot-v1`　｜　运行时模板：`data/prompts/suggestion.txt`　｜　配置键：`paths.prompt_template`

## 1. 运行时模板全文

下列代码块与 `data/prompts/suggestion.txt` 逐字一致；`python scripts/verify.py` 会断言两者一致，避免文档与代码脱节。模板不写死在代码里，由 `app/advisor.py::_build_prompt` 读取并注入 `{rule_text}`。

```text
你是「北辰在线学院 学习支持与辅导协作」系统的建议草稿生成器。
你的输出只进入人工复核队列，不会自动发送、不会自动联系学生、不会写入学生档案。

硬性规则：
1. 只依据下面给出的「已核实规则化事实」复述，不得补充任何未给出的学生信息。
2. 不得给学生定性、评分、分档或判断是否掌握；不得依据个人特征推断能力。
3. 不得建议自动发送消息；结论只能是「请人工核对」。
4. 不得输出字段名、JSON、编号列表或解释；只输出一句不超过 80 字的中文提示。
5. 若信息不足，只输出：请人工核对原始记录与待确认字段。

已核实规则化事实（非学生个人信息）：
{rule_text}

请只输出一句中文提示文本：
```

## 2. 变量与调用链

| 项 | 说明 |
| --- | --- |
| `{rule_text}` | 由 `app/advisor.py::_rule_text(ticket)` 生成的**已核实规则化事实**，不含学生个人信息、不含敏感属性 |
| 生成规则 | 固定开场「建议人工核对原始记录与待确认字段」；连续求助追加次数陈述；高播放时长追加「不能认定已理解，转人工核对」；固定结尾「不构成学生能力判断，人工确认后才可联系学生」 |
| 调用入口 | `build_suggestion` → `_build_prompt` → `_call_model`（按 `model.provider` 分发） |
| 本地模型 | Ollama `/api/generate`，`stream=false`、`think=false`、`temperature=0`、`num_predict=model.max_tokens` |
| 离线模式 | `model.enabled=false` 时不调用模型，直接以 `rule_text` 作为建议文本，`model_provider=offline_rule` |
| 模板缺失 | 退化为纯 `rule_text`，不静默伪造提示词；`verify.py` 会检查占位符存在 |

## 3. 输出之后还要过的三道卡

1. **文本级审查** `_check_model_text`：模型输出不得为空，且不得命中 `security.banned_text_terms`（年龄、性别、民族、宗教、残疾、家庭收入、能力不足、智力低下）；命中按 `SENSITIVE_ATTRIBUTE` 拦截并触发停止条件。空输出返回 `MODEL_ERROR`，不冒充建议。
2. **结构化审查** `review_suggestion`：建议必须带 `fact_refs`（`source_ref` / `event_time` / `channel`），不得含 `banned_outputs` 或 `sensitive_attributes` 字段，不得为 `mode=overwrite`。`knowledge_refs` 只是规则引用，不能充当行为证据。
3. **人工确认门禁**：建议进入 `SUGGESTION_PENDING` 挂起状态；接手确认 + 本人人工确认后才允许联系学生。模型输出不改写 `fact_refs`，不触发任何对外动作。

## 4. 失败策略（不静默冒充）

| 情况 | 行为 |
| --- | --- |
| `model.enabled=false` | 离线规则文本，`model_provider=offline_rule` |
| 地址/模型名未配置、连接失败、超时、空响应 | 返回 `MODEL_ERROR`，不生成建议 |
| `offline_fallback=true` 且模型失败 | 规则文本追加「【模型不可用，本条为离线规则提示，不是模型输出】」，`model_provider=explicit_rule_fallback` |
| 思考型模型只返回 `thinking`、正文为空 | 明确提示设置 `model.think=false` 或增大 `model.max_tokens` |

## 5. 真实输出示例（本机 Ollama `qwen3.5:4b`）

```
请人工核对原始记录与待确认字段，同一学生多次求助需检查漏接，高播放时长须暂停理解判定并转交运营员。
```

该文本仍只进入人工复核队列，不构成结论、不自动发送、不写入学生档案。

## 6. 修改流程

1. 同时修改 `data/prompts/suggestion.txt` 与本文件的模板代码块。
2. 跑 `python scripts/verify_local_model.py` 验证离线 / 失败 / 显式降级 / 真实生成四条路径。
3. 跑 `python scripts/verify.py`，其中「提示词文档与运行时模板一致」会校验两者逐字一致。
4. 若新增禁止判断词，写入 `config.yaml` 的 `security.banned_text_terms`，不要写死在代码里。
